# Portfolio Project (Lab 2)

Personal portfolio page styled with an external stylesheet (`style.css`).

## Files
- `index.html` – semantic structure (header, nav, main, sections, footer)
- `style.css` – all styling, commented by section
- `images/profile.svg` – profile photo

## Features
- Colour theme: blue `#0047ab`, light grey `#f4f4f4`, dark text `#222222`
- Poppins font via Google Fonts
- Sticky header, styled nav with hover effects
- Styled skills table (alternating rows), project cards, contact form with labels and validation
- Fixed "Back to Top" button and smooth scrolling
- `<hr>` separators and box shadows

## Verification
All sections (header, About, Skills, Projects, Contact, footer) are styled and tested in a browser.
